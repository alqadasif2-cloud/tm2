# TForwarder Web — Telegram Auto Forwarder 🚀

تطبيق ويب متكامل لإعادة توجيه رسائل تيليجرام تلقائياً بين القنوات والمجموعات والمحادثات مع فلاتر الكلمات المتقدمة وخيار الإرسال كنسخة نظيفة، مبني اعتماداً على تطبيق الأندرويد **TForwarder (Kotlin/TDLib)**.

---

## ✨ المميزات الرئيسية (Core Features)

1. **إدارة قواعد التوجيه (Rules Engine)**:
   - إنشاء وتعديل وحذف وتفعيل/تعطيل قواعد التوجيه بنقرة واحدة.
   - تحديد عدة قنوات/مجموعات كمصادر (`sources`) وقناة أو مجموعة كوجهة (`dest`).
   - تصدير واستيراد القواعد بصيغة JSON.

2. **فلاتر الكلمات المتقدمة (Keyword Filters)**:
   - **كلمات يجب توفرها (`include`)**: تمرير الرسائل التي تحتوي على واحدة على الأقل من الكلمات المفتاحية (أو تركها فارغة لتمرير الكل).
   - **كلمات مستثناة (`exclude`)**: استبعاد وحجب أي رسالة تحتوي على أي من الكلمات المحظورة (مثل سبام، إعلانات، إلخ).

3. **خيار الإرسال كنسخة نظيفة (`asCopy`)**:
   - إرسال الرسائل دون رأس "تم التحويل من" ورابط القناة الأصلية (Clean Copy).
   - أو التوجيه المباشر بالرأس الأصلي.

4. **إحصائيات وعداد التوجيه اليومي (`Store.today()` & `Store.inc()`)**:
   - عداد مباشر لعدد الرسائل الموجهة خلال اليوم.
   - إجمالي عدد الرسائل الموجهة عبر النظام.

5. **الربط المباشر برقم الهاتف (Direct Phone & QR Linking)**:
   - **بدون الحاجة إلى API أو مفاتيح برمجية**: تسجيل الدخول المباشر برقم الهاتف مثل Telegram Web.
   - اختيار الدولة ورمز الاتصال (اليمن +967، السعودية +966، مصر +20، وغيرها).
   - استلام رمز التأكيد داخل تطبيق تيليجرام الرسمي مباشرة.
   - دعم التحقق السحابي بخطوتين (2FA Password).
   - إمكانية الربط السريع عبر مسح **رمز QR Code** من تطبيق الهاتف (الإعدادات > الأجهزة > ربط جهاز جديد).


6. **محاكي واختبار التوجيه المباشر (Live Message Simulator)**:
   - إرسال رسائل تجريبية واختبار استجابة القواعد والفلاتر لحظياً.
   - نصوص جاهزة سريعة وتحديد أنواع الوسائط (نص، صورة، فيديو).
   - محاكاة تلقائية مستمرة (Auto-Ticker) لاختبار عمل النظام التلقائي في الخلفية.

7. **معاينة حية لمحادثة الوجهة (Destination Chat Preview)**:
   - واجهة تيليجرام حية تُظهر الرسائل التي وصلت إلى القناة المستهدفة مع تمييز النسخ النظيفة عن التوجيه المباشر.

8. **سجل النشاط والتدقيق (Forwarding Activity Log)**:
   - سجل فوري لكافة العمليات مع توضيح سبب التوجيه أو الاستبعاد بالفلاتر.

9. **ربط اختياري مع Telegram Bot API**:
   - إمكانية إضافة Bot Token من `@BotFather` لإرسال الرسائل المحولة حقيقةً إلى تيليجرام.

10. **واجهة ثنائية اللغة (عربي / إنجليزي)**:
    - دعم كامل لاتجاه النص RTL للغة العربية و LTR للإنجليزية.
